# personal  portfolio website

Welcome to my personal  portfolio! This project was crafted to showcase my creative eye behind the lens and my technical journey in frontend web development. 

## 🚀 About the Project
This portfolio is an interactive gallery featuring a curated collection of my photography and technical skills. Originally built with vanilla web technologies, it has been recently migrated to **React + Vite** and now features a unique **Hogwarts Theme**, blending magical aesthetics with smooth, modern performance. 

This repository serves as my submission for the upcoming college competition, highlighting the intersection of digital storytelling and frontend engineering.

## 💻 Tech Stack
*   **Frontend Framework:** React (via Vite)
*   **Core Languages:** HTML5, CSS3, JavaScript
*   **Deployment:** Vercel

## ✨ Key Features
*   **Hogwarts-Inspired UI:** A magical, thematic user interface.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Dynamic Gallery:** Smooth loading and interactive viewing of curated frames.

## 🏆 Competition Highlights
*   **Performance-Driven:** Fast load times utilizing Vite's optimized build process.
*   **Modern Architecture:** Clean component structure and modern JavaScript practices.
*   **Immersive UX:** A strong focus on visual presentation and user experience to keep visitors engaged.
